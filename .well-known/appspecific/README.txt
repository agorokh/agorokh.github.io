This folder hosts the Tesla Fleet API third-party PUBLIC key.

During Home Assistant Tesla Fleet setup, HA displays a public key.
Save it here as:  com.tesla.3p.public-key.pem
(GitHub → Add file → Create new file in this folder, or commit it via git.)

Tesla fetches it at:
https://agorokh.github.io/.well-known/appspecific/com.tesla.3p.public-key.pem

The repo-root .nojekyll file is what allows GitHub Pages to serve this
dot-folder — do not delete it.
